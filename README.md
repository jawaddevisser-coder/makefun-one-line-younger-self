## The line

> The job you're killing yourself to keep will forget your name the week you leave — go home for dinner.

The one line an older self would send back: specific, hard-won, and warm rather than sentimental — a life actually lived, landing in one breath.

## How it works

`main.ts` writes the single line to `/output/entry.txt`. The sealed scorer checks that the file is UTF-8 text of 1 to 200 characters, not only white space; the program itself refuses to write a line outside that range.

Run it with:

```sh
node main.ts
```
